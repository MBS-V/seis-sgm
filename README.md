# seis-sgm
Reproduction of "Posterior sampling for random noise attenuation via score-based generative models" (Meng et al., Geophysics 2025).
Authors' code is pinned in `vendor.lock` and fetched into `vendor/` (never edited). Our code lives in `src/` and `scripts/`.

- Local (Windows, VS Code): edit code, commit, push.
- Colab: open `notebooks/00_bootstrap_s1.ipynb`, run top to bottom. Data, checkpoints and logs go to `MyDrive/seis_sgm/`.
